== Description ==

GutenStyle is a visual styling system for native WordPress blocks.

Development source and build documentation:
https://github.com/tenfic/gutenstyle

== Installation ==

1. Upload and activate GutenStyle.
2. Open GutenStyle in the WordPress admin.
3. Configure styles.
