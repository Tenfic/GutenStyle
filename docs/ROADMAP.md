# GutenStyle Roadmap

## Milestone 0 - Foundation
- Plugin bootstrap
- TypeScript/React build
- Admin application shell
- REST foundation
- Style registry
- Public extension hook
- Free/Pro architectural boundary
- Local WordPress development

## Milestone 1 - Style engine
- Complete: typed property schema and strict sanitizer
- Complete: versioned Global option, Post metadata, and block attribute contracts
- Complete: property-level resolver with origin metadata and preset merging
- Complete: CSS custom-property compiler plus WordPress Style Engine mapping boundary
- Complete: effective-style service and public Free extension hooks
- Complete: secure schema, preset, and Global-style REST contracts
- Complete: PHP 7.4 unit and syntax test tooling

## Milestone 2 - Table proof of concept
- Core table adapter using the native `core/table` block
- Initial declarative presets
- Global table settings
- Post table override
- Individual table override
- Live editor preview
- Frontend parity

Milestone 2 remains intentionally unstarted until the generic engine is reviewed.
